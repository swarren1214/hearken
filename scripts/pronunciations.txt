# Hearken pronunciations: how Listen mode says names the voices would otherwise guess at.
#
# One name per line:   Name | respelling
# Respellings follow the Book of Mormon Pronunciation Guide's key. Separate syllables with "-"
# and put ʹ (or ') right after the stressed syllable: Moroni | mō-rōʹnī
#
#   a  about     ă  map      ā  way      ä  father   â  care     ô  law
#   ĕ  bed       ē  me       er permit   ĭ  him      ī  idle     ō  bone
#   ou about     u  jump     ū  rule     o  hot      e  bed      i  him
#   ch chin      sh ship     th thin     zh measure  j  jump     g  go      y  yes
#
# To give Kokoro exact phonemes instead, start with "/":  Kolob | /kˈOlɑb
# After editing, run:  python3 scripts/build_pronunciations.py
# Plurals and "-ites" forms are added automatically (Nephite → Nephites).

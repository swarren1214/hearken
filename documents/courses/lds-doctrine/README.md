# Latter-day Saint Doctrine course package

Start with [the complete curriculum](CURRICULUM.md).

- **CURRICULUM.md** — eight courses from Novice through the Sage capstone; 32 original articles, 92 required readings, 60 exercises, 12 optional reading placements, eight YouTube selections, and four book recommendations.
- **ASSESSMENT_GUIDE.md** — 80 course-checkpoint questions, 20 advancement questions, reading answer guides, scoring rules, and the capstone rubric.
- **curriculum.json** — structured editorial master with stable IDs, prerequisites, XP, source perspectives, rights dispositions, completion evidence, and answer guides. Requires an adapter to the current app.
- **SOURCES_AND_RIGHTS.md** — source-by-source provenance, links, and include/link/embed/recommend dispositions.
- **IMPLEMENTATION.md** — how this path maps into Hearken and which app capabilities need support.
- **VALIDATION_REPORT.json** — current validation results, including all 89 scripture locator placements checked against Hearken's existing content.
- **validate_curriculum.py** — repeatable integrity check.

Required path: **5,000 subject XP**. Milestones: Apprentice at 500, Investigator at 1,500, Scholar at 3,000, Sage at 5,000, each with its required gates. No paid material or video playback is necessary. This package is authored and mechanically validated; doctrinal/editorial review, app integration, and in-app playback testing remain before production release.

The earlier [Scholar path rules](../scholar-path/PROGRESSION.md) and [badge assets](../scholar-path/badges/) apply to this course.
